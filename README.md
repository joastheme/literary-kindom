# Literature Club

## O que é?

É um fórum de literatura que visa conectar leitores de todo o mundo por meio de uma aplicação web.

O site se consiste em uma pagina na qual se pode ler artigos/resenhas dos seus livros prediletos como
tambem escrever-las, conectando suas ideias a dos seus colegas a passo que estimula a interação social
ao conhecer pessoas com interessses em comum.
